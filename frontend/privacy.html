Kebijakan Privasi

EcoMatch · Berlaku sejak 2026 · Sesuai UU No. 27 Tahun 2022 tentang Pelindungan Data Pribadi (UU PDP)

1. Data yang kami kumpulkan

  • Akun: nama, email, kata sandi (disimpan ter-hash dengan bcrypt), peran, status verifikasi
  • Opsional: nomor telepon, alamat, koordinat lokasi (lat/lng), nama organisasi, kapasitas kurir
  • Aktivitas: catatan sampah makanan, klasifikasi AI, alokasi routing, status pengantaran, log audit
  • Teknis: log error terstruktur (method, path, status) untuk keamanan layanan

2. Tujuan penggunaan

  • Mengalihkan sampah makanan MBG dari donor ke TPS pengolah beserta kurir penjemput
  • Autentikasi, verifikasi akun, notifikasi pengantaran (in-app / WhatsApp / email bila diaktifkan)
  • Keamanan, audit, dan peningkatan layanan

3. Dasar & batas pemrosesan

Kami hanya memproses data yang diperlukan untuk tujuan layanan. Data tidak dijual, disewakan, atau dipakai untuk iklan pihak ketiga. Koordinat digunakan untuk perhitungan rute dan ditampilkan sebagai bagian dari fitur peta operasional.

4. Pihak ketiga (opsional)

Jika Anda mengaktifkan notifikasi eksternal, data terbatas (nomor WhatsApp / email tujuan, isi pesan status) dikirim ke penyedia gateway yang Anda setujui (mis. CallMeBot, SMTP). Tanpa konfigurasi tersebut, notifikasi hanya tersimpan di aplikasi (outbox simulasi).

5. Penyimpanan & keamanan

  • Kata sandi tidak pernah disimpan dalam bentuk asli
  • Token sesi (JWT) kedaluwarsa otomatis
  • Database dienkripsi/diakses sesuai penyedia hosting (mis. Turso) dengan token autentikasi
  • Backup database dilakukan berkala oleh pengelola

6. Hak Anda (sesuai UU PDP)

  • Memperoleh informasi pemrosesan data pribadi Anda
  • Memperbaiki atau memperbarui data yang tidak akurat
  • Menghapus data / menarik persetujuan (hubungi admin) — berlaku untuk data yang tidak wajib disimpan demi audit/hukum
  • Mengajukan keberatan atas pemrosesan

7. Retensi

Data akun dan log audit diselama layanan berjalan. Saat penghapusan diminta, data non-operasional dihapus atau dianonimkan; sebagian catatan audit dapat tetap disimpan dalam bentuk minimal untuk integritas sistem.
